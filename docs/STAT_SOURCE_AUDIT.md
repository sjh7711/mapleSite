### 2. 선택 프리셋에만 있는 장비 세트 복원

현재 활성 장비의 세트 API 응답을 기준으로 세트 인원 차이를 적용한다. 활성 장비에 세트 항목 자체가 없으면 선택 장비에서 새로 성립하는 세트의 이름과 효과를 구하지 않는다. 세트를 확인할 수 없다는 표시도 빠진다. 합성 표본으로 장비 2번에 마이스터링과 마이스터 이어링을 넣었을 때, 활성 세트 응답이 빈 배열이면 결과의 세트와 경고가 모두 비어 있었다. 같은 입력에 세트 정의를 제공하면 두 장비가 집계되고 2세트 효과가 적용되었다. 합성 효과 수치는 테스트용이다. [`setEffectDataForEquipment`](../maple-core/src/stat-efficiency.js)

선택 장비에 있는 세트까지 조회 가능한 세트 정의와 대조하고, 수치나 럭키 아이템 조건을 확인할 수 없는 조합을 표시한다. 활성에 없는 세트의 신규 성립, 활성 세트 증감, 프리셋 간 무변경을 검증한다. 이번 조사에서 실제 세 캐릭터의 효율 차이가 이 사례로 생겼다는 증거는 확보하지 못했다.

### 3. 유피테르의 기어드락 심볼 효과 누락

넥슨 심볼 가이드는 그랜드 어센틱심볼 기어드락 Lv.11 이상에 유피테르 공격 시 데미지 +20%를 명시한다. 현재 대상 매핑에는 유피테르가 없다. Lv.11 심볼을 넣고 대상 유피테르로 계산하면 효과가 비고, 같은 방식으로 Lv.11 세르니움과 세렌을 넣으면 +20%p가 나온다. 기본 대상 세렌의 현재 결과에는 영향이 없다. 유피테르를 대상으로 평가할 때 Lv.10은 0, Lv.11 이상은 +20%p, 다른 보스는 0으로 검증한다. ### 4. 실전 버프 중첩과 비교용 크확의 기준 명시

### 합산식과 환산 단위

- **스탯** — `floor(% 적용 대상 × (1 + 스탯% / 100)) + % 미적용 스탯`. 렌·궁수·마법사 등은 무기 계열과 주·부스탯을 사용하고, 제논은 STR·DEX·LUK를 사용한다. 하이브리드 로직은 올스탯 10% 출처로 읽는다. 코드에는 2026-09-17 전후 제논 헥사 주력 스탯 계수 0.48 → 0.66이 있다. [2026-09-17 넥슨 직업 조정](https://maplestory.nexon.com/news/update/812?page=1)
- **헥사 스탯** — 표시 레벨에서 산출한 단위를 사용한다. 일반 주력 스탯 100, 공·마 5, 보공 1%p, 데미지 0.75%p, 크뎀 0.35%p, 독립 방무 1%가 단위당 수치다. 공격력 전용 옵션을 마력에 합산하지 않는다. [헥사 합산 코드](../maple-core/src/stat-efficiency.js)
- **공격력·마력** — `floor(출처별 정수 합 × (1 + 공·마% / 100))`. 창에 표시되는 공격력과 효율식의 % 적용 전 공격력은 다른 단위다.
- **보총뎀** — `100 + 데미지% + 보스 몬스터 데미지% + 해당 조건에서 적용되는 추가 데미지%p`가 배율의 분모다. 같은 조건에서 +40%p의 최종뎀 효율은 `40 / 분모 × 100`이다. 상태이상, 링크, 링, 보스 전용 심볼, 특수 코어를 각각 기록해 중복을 피한다.
- **방무와 최종뎀** — 전역 방무는 `1 - product(1 - 각 방무 / 100)`. 방어율 300/380은 배율 3.0/3.8이고, 스킬별 방무나 적의 방어율 감소는 따로 적용한다. 독립 최종뎀 출처는 `product(1 + 각 최종뎀 / 100)`으로 곱한다.
- **크뎀과 단위 변환** — 크리티컬 100% 기준 평균 크리티컬 배율은 `1.35 + 크뎀% / 100`. 크리티컬 리인포스는 학습한 스킬과 극딜 구간 피해 가중치를 쓴다. 사이트 옵션 카드의 `주스탯%`과 `최종뎀%`는 같은 증가를 서로 다른 단위로 표현한다. 같은 옵션 입력과 단위에서 비교한다. [전투·환산 코어](../maple-core/src/stat-efficiency.js) · [옵션 값 표시](../maplestarforce/src/shared/character-profile.js)
- **데몬어벤져** — HP 추옵은 기존 별도 환산식을 사용한다. 공통 출처 엔진의 전투 수치 검증 결과를 그대로 옮길 수 없다. 공개 자료가 부족한 HP는 검증표에서 계산값이 비어 있을 수 있다. 장비 또는 스킬 원본이 부족하면 API 호환 경로가 남아 있고, 응답의 `statCalculationBasis`로 확인할 수 있다. ### 재현 순서

1. **인게임에서는 수치의 출처를 기록한다.** 같은 프리셋에서 스탯창과 필요한 툴팁을 캡처한다. 데미지·보공·방무·크확·크뎀·공/마·주스탯·벞지, 도핑·이벤트·펫 버프·소환·링 발동·링크 스택·특수 코어를 기록한다. 차이가 있는 효과만 한 번에 하나씩 바꾼다. API 갱신은 넥슨 안내 기준 평균 15분이다. 여러 엔드포인트 응답을 같은 시각으로 단정하지 않고 조회 시각과 실제 프리셋을 함께 보관한다. [넥슨 API 응답과 갱신 안내](https://openapi.nexon.com/game/maplestory/)
2. **우리 사이트에서는 활성과 보스 선택을 각각 읽는다.** `/api/character-conversion`에서 `presetMode=active/auto/manual`을 비교한다. `presetSelection.active`, `presetSelection.selected`, `profiles.fullBoss.details.statVerification`, `selectedStatTotals`, `statCalculationBasis`, `combatModel.effects`를 확인한다. 선택 보스와 활성 API가 다른 경우 API 검증표는 활성끼리 비교하고, 보스는 선택 프리셋의 출처와 전투 기록을 비교한다. [변환 API](../maplestarforce/functions/api/character-conversion.ts) · [검증 계산](../maplestarforce/functions/_lib/stat-verification.ts)
3. **환산주스탯에서는 효율과 입력을 기록한다.** 같은 장비·하이퍼·유니온·링크·어빌리티, 목표 보스·방어율, 리레·컨티 레벨과 도핑을 맞춘다. 먼저 시뮬레이터 추가 스탯 0에서 세부 효율을 기록하고, 원인 분리가 필요한 경우에만 보총뎀 0/40을 한 항목씩 바꾼다. 옵션 입력량과 표시 단위를 남긴다.
4. **수정 전후의 차이를 하나씩 재생한다.** 버프가 포함된 게임 스냅샷의 총계를 기준치로 저장하는 방식 대신 공통 합산에서 직접 변화가 발생하도록 한다. 테스트는 시드링·도핑·스킬 미습득·목표 보스·프리셋 조합을 확인한다. 보관 자료에는 인증 키나 API 식별자를 포함하지 않는다.

### 레테신쫑 리레 0 대조

사용자가 제출한 컨티 4·풀도핑의 리레 0 캡처를 기존 리레 4 캡처와 대조했다. 보총뎀 +40은 50.83, 방무 +40은 보스 300에서 22.39와 보스 380에서 28.71이었다. 마력 +30과 크뎀 +8도 양쪽 캡처에서 각각 9.92와 32.87이었다. 두 캡처에 근거해 리레의 반지 배율은 보총뎀·방무 효율 차이의 직접 원인에서 제외한다. 51.84는 실제 전투의 버프 중첩을 추정한 수치다.

마력% +12는 환산주스탯에서 리레 4의 57.23에서 리레 0의 64.33으로 올랐다. 같은 운영 응답에서 리레 효과만 제거하면 58.05에서 64.24로 올랐다. 환산주스탯의 마력% +12 최종뎀 4.662%와 두 주스탯% 결과의 비율을 이용해 역산한 리레 4의 유효 마력은 약 +28.41%p다. 운영 값은 +24.39%p다. 리레 0에서 양쪽의 유효 마력은 약 129%로 맞았다. 사용자 캡처의 시뮬레이터에서 리레 제거 시 보스 300 최종뎀은 −11.036%였고, 운영의 마력% 배율로 같은 제거를 계산하면 −9.627%였다.

### 레테의 확률 재사용과 소울 컨트랙트 사용 횟수

레테신쫑의 어빌리티 3번 재사용 미적용 20%와 아티팩트 7.5%를 동일 원본에서 제거해 재생했다. 세 이딕트 공격의 가중치와 보총뎀·방무 효율이 같았다. 운영은 선택한 장비·유니온 쿨감으로 적용 가능한 시전 주기를 줄인다. 이딕트 공격 비중은 연무장 표본에서 가져오며, 선택한 프리셋의 확률로 다시 계산하는 경로가 없다. 레테 연무장 12건의 어빌리티 재사용은 17–20%, 아티팩트는 모두 7.5%였다. 관측된 공격 비중에는 이 재사용이 이미 반영돼 있다. [넥슨 쿨감과 재사용 미적용 설명](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/390)

레테신쫑의 템플러 아츠·램페이지는 일반 구간에서 어빌리티 20% + 아티팩트 7.5% + 어튠먼트 15%로 42.5%다. 체인 커맨드의 맹약 최종 완성 구간에는 12%p가 더해져 54.5%다. 최종 완성 시의 즉시 초기화와 30초간 이딕트 쿨타임 40% 감소가 따로 있다. 재사용을 바로 이어가고 판정이 독립이라는 가정에서는 쿨이 걸리기 전 시전 횟수의 기대값이 각각 1.74회와 2.20회다. 실제 공격 시간과 오버로드 사용 중 잠금으로 시전 횟수는 달라진다. 펠 스톰은 자동 발동이며 어튠먼트 적용 범위에서 빠진다. [레테 체인 커맨드 업데이트](https://maplestory.nexon.com/News/Update/809)

사용자 조건에 따라 소울 컨트랙트는 극딜·준극딜에 한 번씩 시전한다. 기존 6분 비교에서 극딜 3회와 준극딜 3회로 두면 벞지 71%의 지속시간 17.1초를 6회 적용하므로 시간 기준 평균 데미지는 +17.10%p다. 운영의 17.1초 / 53.4초 주기에서 계산된 +19.21%p를 교체했다. 이 조건만 반영한 보총뎀 +40 효율은 53.50이고, 이딕트와 앱솔루트 레인의 고유 보공을 추가하면 53.04다. 연무장 12건의 각 리레 시점과 그 사이 중간 시점에 소울 컨트랙트를 한 번씩 배치해 기존 피해 가중 분석도 다시 돌렸다. 그 결과는 51.94로, 기존 51.84보다 0.10%p 높다. 이 추정에는 이딕트의 프리셋별 재사용 확률로 공격 비중을 바꾸는 효과가 들어 있지 않다.

### 프리셋별 재사용 기댓값 반영

선택한 어빌리티의 재사용과 유니온 아티팩트의 소수점 확률을 합산한다. 공격은 대기시간 미적용 성공 후 다시 판정할 수 있으므로, 별도 제약이 없는 직접 시전의 기대 횟수는 `1 / (1 - p)`다. 선택 확률에서의 기대 횟수를 연무장 표본 확률에서의 기대 횟수로 나누고, 그 비율로 대상 공격의 피해 점유율을 바꾼다. 보스 프리셋 선택에서도 대상 공격의 기대 피해 변화가 점수에 들어간다. 기존 표본이 이미 반영한 재사용 기여도는 이 비율을 통해 중복 가산을 피한다. 48직업의 현재 공개 스킬을 기준으로 직접 사용과 자체 쿨타임을 확인했다. 원본이 적용 대상인 VI 마스터리에도 현재 설명상 예외가 없는 경우 적용한다. 자동 발동, 충전 간격, 초기화 제한이 있는 기술, 하이퍼 액티브와 5차, 별도 6차 기술은 구분한다. 공격 가중치에 적용한 범위는 연무장 표본과 연결된 28직업 57개 공격 항목이다. 패스파인더와 메르세데스는 운영 공격 비중의 원본과 재사용 표본 기수가 달라 확인한 동직업 상위 기록의 확률을 근사값으로 사용한다. 현재 수집한 표본과 연결하지 못한 공격은 차후 확인 대상이다. [스킬별 재사용 계산](../maple-core/src/combat-reuse.js) · [재사용 표본 확률](../maple-core/src/battle-practice-reuse-references.js)

재사용 가능한 자체 버프는 이미 적용된 장비·유니온 쿨타임을 사용하며, 성공하면 버프가 끝난 뒤 다시 켠다고 가정한다. 소울 컨트랙트는 사용자 가정에 따라 2분 극딜과 사이 준극딜마다 한 번 적용한다. 실제 전투의 시전 지연, 자원·연계 제약, 보스 기믹과 재사용 결과가 리레 창의 타격 순서를 바꾸는 효과는 이 평균 모델에 포함되지 않는다. 레테는 어튠먼트와 체인 커맨드의 맹약 구간 확률·쿨타임을 별도로 반영한다. [레테 이딕트 공식 수정 안내](https://maplestory.nexon.com/News/Update/809)

### 확인된 직업별 방무와 보공 누락 수정

- 스트라이커의 뇌전은 엘리멘트의 기본 2중첩에 뇌백·뇌제·뇌신의 상한 증가를 합산한다. 만렙 보스전에서 5중첩 유지 조건의 방무는 일반 구간 45%, 천지개벽 구간 50%다. 6분 전투에서 천지개벽 기본 지속 30초와 쿨타임 120초를 쓰면 평균 방무는 46.25%다. 태풍 VI의 보너스도 같은 중첩 상한과 습득한 지속시간 효과를 사용한다. [넥슨 스트라이커 스킬 변경](https://maplestory.nexon.com/News/Update/676)
- 아크는 스펠의 타격 지속시간과 적중으로 얻는 캐릭터 버프를 분리한다. 어비스 차지드라이브 VI 툴팁의 3초는 스펠 공격이고, 60초 버프가 데미지·보공·방무를 올린다. 배틀 아츠의 방무·보공은 적용 범위의 직접 공격에 연결한다. 제외 대상으로 명시된 스킬에는 해당 하이퍼를 추가하지 않는다. [넥슨 아크 스킬 설명](https://gi.maplestory.nexon.com/Guide/GameInformation/Skill/Ark) · [현재 수치의 출처](https://openapi.nexon.com/ko/game/maplestory/)
- 스킬 전용 방무의 대상이 공격 계열이나 여러 공격으로 명시되면 실제 공격 이름으로 연결한다. 암살, 미스트 이럽션, 레테의 이딕트, 라라의 분출·흡수, 키네시스의 얼티메이트, 패스파인더의 포스 계열 등에서 확인했다. 트리니티와 트리니티 퓨전, 데스와 데스 블로우, 리볼빙 캐논과 마스터리는 각 공격 이름에 일치하는 출처를 우선한다. 다크나이트의 비홀더와 일리움의 II→VI 강화는 공식 설명대로 연결을 유지한다.
- 대상이 확인된 하이퍼 보공 및 레테 앱솔루트 레인의 습득 레벨별 보공은 해당 공격의 현재 데미지 배율에만 포함한다. 공통 보공 +1의 효과는 공격별 한계 효율을 방어율 380%에서의 피해 비중으로 평균한다. 스킬 보공은 캐릭터 전역 보공에 합산하지 않는다. 해당 공격의 점유율이 없는 자료는 기존 공통 계수를 적용한다. [공격군 반영 코드](../maple-core/src/combat-model.js)
- 캡틴 파이렛 플래그는 원본 툴팁의 보스 전투 방무 효과가 확인됐다. 타 계산기의 포함 여부를 추정해 제거하지 않았다. 카인의 4차 이하 처형 효과가 VI에 계승되는 범위와 제로 폼별 실전 공격 비중은 추가 확인이 필요하다.
