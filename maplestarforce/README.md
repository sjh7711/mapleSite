# 메이플 스타포스 기댓값 계산기

여러 장비를 한 번에 계산하는 웹 계산기입니다.
`https://maple.hoegifarm.duckdns.org/starforce/` 에서 서비스합니다.

## starforce.gg와 다른 점

- **여러 장비를 한 번에** 넣고 합계를 바로 봅니다. 장비마다 개수도 지정할 수 있어
  기댓값을 직접 더할 필요가 없습니다.
- 합계에 **1배 · 1.05배 · 1.08배 · 1.1배**를 함께 보여줍니다. 실제 결과가
  기댓값보다 나쁠 때를 대비해 자금을 얼마나 더 잡을지 판단하는 용도입니다.
- **시작 성**을 장비마다 바꿀 수 있습니다. 보통은 12성이라 평소에는 감춰 두고
  `시작 성 직접 지정`을 켰을 때만 나타납니다.
- 1억 메소 시세를 넣으면 현금 환산액을 함께 보여줍니다.

## 계산 기준

기댓값 계산은 공용 패키지 [`maple-core`](../maple-core)에 있습니다. Discord 봇도
같은 패키지를 쓰므로 두 곳의 계산 결과가 어긋나지 않습니다. 빌드하면 결과물에
번들되어 배포본은 어느 폴더에도 의존하지 않습니다.

- 2026-03-19 개편 이후 일반 장비 기준입니다.
- 삭제된 스타캐치의 성공확률 1.05배 보정을 항상 적용합니다.
- 각 단계마다 12성 복구·확정 복구·파괴 방지 중 기대비용이 가장 낮은 방법을
  자동으로 선택하며, 23성 이상에서 파괴되면 22성으로 복구되는 규칙도 반영합니다.
- 슈페리얼, 제로/데스티니 무기, 아스트라 보조무기의 별도 복구 비용은
  계산 대상이 아닙니다.

## 구조

```text
maple-core/          기대값 계산 (Discord 봇과 공용, 의존성 없음)
maplestarforce/
  index.html         스타포스 페이지
  src/
    main.js          스타포스 화면
    calc.js          장비 목록·기본값·표시 서식
    shared/ui.js     도구가 함께 쓰는 화면 조각
```

계산기를 늘릴 때는 이렇게 나눕니다.

- **계산**은 `maple-core` 에 넣습니다. `discord.js` 나 `document` 처럼 특정 실행
  환경에 묶인 것을 들이지 않아야 봇과 브라우저 양쪽에서 씁니다.
- **화면 조각**(드롭다운·숫자칸·칩·굴려서 바꾸기)은 `src/shared/ui.js` 를 씁니다.
  도구마다 다시 만들면 조작감이 갈라집니다.
- **페이지**는 도구마다 하나씩 만들고 `vite.config.js` 의 `pages` 에 더합니다.
  번들이 갈라져 안 쓰는 계산기 코드를 내려받지 않습니다.
- **저장 키**는 `maplestarforce:<도구>:<판>` 처럼 도구 이름을 넣어 서로
  덮어쓰지 않게 합니다. 스타포스는 `maplestarforce:v4` 를 씁니다.

## 개발

```bash
npm install
npm run dev     # http://localhost:5174
npm run build   # dist/ 생성
```

`maple-core`를 `file:../maple-core`로 걸어 두었으므로 `../maple-core` 폴더가
있어야 `npm install`이 됩니다. 설치가 끝나면 빌드는 그 폴더 없이도 됩니다.

### 장비 시세 모델 검증

공개 시세 데이터의 과거 80%로 학습하고 최신 20%를 예측해 장비별 오차를
확인합니다. 구성요소 합계, 캐릭터 프로필에 따른 시장 총액 불변성, 표본 밖 입력
안전성도 함께 검사합니다.

```bash
npm run market:model-check
```

전체 장비 공통 계수를 로컬 모델에 섞는 실험은 아래 명령으로 비교합니다. 이
결과는 연구용이며 현재 브라우저 추정기에는 자동 적용하지 않습니다.

```bash
npm run market:prior-check
```

## 배포

정적 파일이라 별도 서버 프로세스가 없습니다. 빌드 후 nginx가 `dist/`를 직접
서비스합니다.

```bash
npm run build
```

nginx 설정은 `/etc/nginx/conf.d/maple-activity.conf` 의 `location /starforce/`
입니다. 같은 vhost의 `location /` (Discord Activity용 127.0.0.1:3000 프록시)보다
먼저 매칭되며, 루트 도메인(`hoegifarm.duckdns.org`)과 `monitor.` 서브도메인
설정은 건드리지 않았습니다.
