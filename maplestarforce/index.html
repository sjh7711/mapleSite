스타포스 계산기 이용 안내

여러 장비의 강화 조건을 한곳에 모아 장비별 평균 비용과 전체 준비 규모를 비교하는 방법을 안내합니다.

계산 순서

  1. 먼저 적용할 이벤트와 MVP·PC방 할인 여부를 실제 강화 계획에 맞게 선택합니다.
  2. 장비 목록에서 품목을 추가하고 현재 스타포스, 목표 스타포스와 스페어 가격을 입력합니다. 캐릭터 조회를 이용했다면 불러온 장비가 맞는지도 확인합니다.
  3. 장비마다 파괴방지와 복구 조건을 정한 뒤 여러 장비의 결과를 합산해 봅니다.

결과 읽는 법

준비할 메소는 선택한 장비들의 평균 강화 비용을 합한 값입니다. 평균 스페어와 평균 시도 횟수는 장기 반복 시의 평균이므로, 표시된 금액이나 개수 안에서 반드시 목표에 도달한다는 뜻은 아닙니다.

장비의 단계별 기댓값을 펼치면 어느 구간에서 비용과 스페어가 많이 드는지 확인할 수 있습니다. 대장장이 배율을 바꾼 경우에는 배율이 적용된 표시값인지 함께 확인하세요.

계산 기준과 한계

화면에서 선택한 강화 규칙, 할인, 파괴방지와 복구 조건을 기준으로 계산합니다. 스페어 가격은 실시간 시세가 아니며 저장값이나 직접 입력한 값을 사용하므로 강화 직전에 다시 확인해야 합니다.

확률·규칙의 근거는 데이터·확률 출처에서, 기댓값의 의미와 공통 주의사항은 이용 안내에서 확인할 수 있습니다.
