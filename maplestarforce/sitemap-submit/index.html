사이트맵 제출

사이트로 돌아가기

Google Search Console

사이트맵을 먼저 확인한 뒤 Google 창에서 최종 제출합니다. Search Console 소유자 계정으로 로그인해야 합니다.

사이트맵을 확인하고 있습니다.
  1. Search Console에서 https://starforce.pages.dev/ 속성을 선택합니다.
  2. 새 사이트맵 추가에 sitemap.xml을 입력합니다. 앞뒤에 /를 붙이지 마세요.
  3. Google 화면의 제출 버튼을 누릅니다.
  4. 기존 항목이 가져올 수 없음이면 위 주소로 다시 제출한 뒤 마지막으로 읽은 날짜와 상태를 확인합니다.
  5. 사이트맵을 읽은 뒤에는 홈페이지를 URL 검사 → 실제 URL 테스트 → 색인 생성 요청 순서로 확인합니다.

이 페이지는 현재 브라우저에서 파일을 읽을 수 있는지 확인합니다. Google의 접근 여부와 색인 상태는 Search Console에서 확인해야 합니다. 사이트맵을 읽는 것과 검색 결과에 페이지가 등록되는 것은 별도 과정입니다.
